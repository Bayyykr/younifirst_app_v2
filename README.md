# 💻 YouniFirst: Platform Kemahasiswaan Terintegrasi Berbasis Mobile dan Website untuk Mendukung Ekosistem Informasi dan Kolaborasi di Politeknik Negeri Jember

## Website Admin & Satpam — Panel Manajemen Terpadu

**YouniFirst Website** adalah panel manajemen terpadu yang digunakan oleh **Admin** dan **Satpam** untuk mengelola ekosistem digital kemahasiswaan POLIJE.

Dengan semangat **"Your First Step to Innovation and Synergy in Technology"**, website ini menghadirkan pengalaman manajemen yang produktif, terstruktur, dan efisien.

---

## 🎯 Target Pengguna

| Peran | Akses |
|-------|-------|
| **Admin** | Manajemen penuh seluruh fitur sistem |
| **Satpam** | Akses terbatas hanya pada fitur Lost and Found |

> ⚠️ **Catatan:** Website ini **tidak** menyediakan akses untuk mahasiswa. Mahasiswa menggunakan aplikasi mobile terpisah.

---

## 📋 Fitur Website

### 1️⃣ Panel Admin

Admin memiliki akses penuh ke seluruh fitur manajemen sistem:

| Menu | Fungsi |
|------|--------|
| **Dashboard** | Melihat ringkasan data, statistik pengguna, event, laporan, dan aktivitas terkini |
| **User Management** | Mengaktifkan, menyuspend (dengan waktu tertentu), memblokir akun mahasiswa, mengisi alasan tindakan, melihat riwayat laporan pengguna |
| **Event Management** | Membuat, mengedit, menghapus, dan memantau seluruh event kampus (seminar, workshop, webinar, turnamen, konser) |
| **Team Monitoring** | Memantau aktivitas pembentukan tim kompetisi, melihat daftar perekrutan, dan riwayat tim yang terbentuk |
| **Lost and Found** | Memantau dan mengelola seluruh laporan barang hilang/temuan |
| **Announcement** | Membuat, mengedit, dan mengirim pengumuman resmi ke seluruh mahasiswa melalui aplikasi mobile |
| **Export Laporan** | Mengekspor data laporan (pengguna, event, tim, lost and found, forum) ke format PDF, Excel, atau CSV |
| **Settings** | Mengatur konfigurasi sistem, pengaturan umum aplikasi, serta manajemen profil admin |
| **Logout** | Mengakhiri sesi login admin |

### 2️⃣ Panel Satpam

Satpam memiliki akses terbatas:

| Menu | Fungsi |
|------|--------|
| **Lost and Found** | Melihat laporan barang hilang dan temuan, memantau status barang, menghubungi mahasiswa terkait untuk membantu pencocokan barang |
| **Logout** | Mengakhiri sesi login satpam |
